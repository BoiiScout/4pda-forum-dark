# 4PDA Forum Dark

Тёмная тема для форума 4PDA в виде userscript для Tampermonkey.

Скрипт предназначен именно для полной версии форума 4PDA на ПК. Он затемняет основные элементы форума и при этом не инвертирует изображения, аватарки и видео.

## Что меняется

- фон форума и сообщений;
- цитаты, спойлеры и блоки кода;
- поля ввода и кнопки;
- всплывающие меню;
- пагинация;
- шапка и подвал форума;
- блок причины редактирования сообщения;
- скроллбар;
- старые светлые блоки, которые иногда встречаются в разметке форума.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте файл [`4PDA-Forum-Dark.user.js`](https://raw.githubusercontent.com/BoiiScout/4pda-forum-dark/main/4PDA-Forum-Dark.user.js).
3. Tampermonkey предложит установить скрипт.
4. После установки обновите страницу форума 4PDA.

Если автоматическая установка не открылась, создайте новый userscript в Tampermonkey и вставьте содержимое файла вручную.

## Поддерживаемые адреса

- `4pda.to/forum/`
- `4pda.ru/forum/`

## Обновления

В скрипте указаны `@updateURL` и `@downloadURL`, поэтому Tampermonkey сможет проверять новые версии через этот репозиторий.

## Ошибки и предложения

Если какой-то элемент форума остался светлым или выглядит неправильно, создайте [Issue](https://github.com/BoiiScout/4pda-forum-dark/issues) и приложите скриншот страницы.
